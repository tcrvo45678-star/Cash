# גיבוי אוטומטי ל-Google Sheets - הוראות פריסה

חלק זה **לא רץ בדפדפן** ולא מגיע לאתר עצמו - זה קוד שרץ בחשבון הגוגל
שלך, בתשתית של גוגל (Google Apps Script). האתר רק שולח אליו נתונים.

## שלב 1: יצירת גיליון חדש

1. פתח/י [sheets.google.com](https://sheets.google.com) ויצר/י גיליון חדש
   וריק. תן/י לו שם (למשל "גיבוי שיבוץ").

## שלב 2: הוספת הקוד

1. בגיליון: תפריט **Extensions → Apps Script**.
2. יפתח עורך קוד עם קובץ ברירת מחדל בשם `Code.gs` שמכיל `function myFunction() {}`.
3. מחק/י את התוכן הקיים, והדבק/י את כל התוכן של הקובץ `Code.gs` שנמצא
   בתיקייה הזו (`shibutz/google-apps-script/Code.gs`).
4. שמור/י (Ctrl+S / כפתור הדיסקט).

## שלב 3: פריסה כ-Web App

1. בעורך הקוד: כפתור **Deploy** (כחול, למעלה מימין) → **New deployment**.
2. ליד "Select type" - לחצ/י על גלגל השיניים ובחר/י **Web app**.
3. במסך שנפתח:
   - **Execute as**: Me (החשבון שלך).
   - **Who has access**: Anyone (חובה - אחרת האתר לא יוכל לשלוח נתונים).
4. לחצ/י **Deploy**.
5. ייתכן שתתבקש/י לאשר הרשאות - אשר/י (זה הקוד שלך, רץ בחשבון שלך).
6. בסיום יוצג **Web app URL** - זו כתובת ארוכה שמתחילה ב-
   `https://script.google.com/macros/s/.../exec`. **העתק/י אותה**.

## שלב 4: חיבור לאתר shibutz

1. פתח/י את אתר shibutz, עבור/י ללשונית **"הגדרות"**.
2. הדבק/י את הכתובת שהעתקת בשדה "כתובת Web App", ולחצ/י **"שמור כתובת"**.
3. לחצ/י **"בדוק חיבור"** - אמור להופיע "✓ החיבור תקין". אם לא -
   ודא/י שב"Who has access" בחרת "Anyone" (שלב 3), ושהעתקת את הכתובת
   המלאה כולל `/exec` בסוף.
4. לחצ/י **"גבה עכשיו"** לבדיקה ראשונה, ואז פתח/י את הגיליון בגוגל -
   אמורות להופיע 4 לשוניות: "חניכים", "אנשי צוות", "חקלאים",
   "היסטוריית שיבוצים".

מכאן והלאה - כל שינוי באתר (הוספת חניך, שיבוץ, וכו') ישלח גיבוי מעודכן
אוטומטית תוך כמה שניות, כל עוד מישהו פתוח על האתר בדפדפן.

## עדכון הקוד בעתיד

אם הקובץ `Code.gs` בפרויקט משתנה (עדכון עתידי) - יש להעתיק את התוכן
המעודכן לתוך עורך ה-Apps Script (שלב 2) ולפרוס גרסה חדשה: **Deploy →
Manage deployments → עריכת ה-deployment הקיים → Version: New version →
Deploy**. כך כתובת ה-Web App נשארת זהה ואין צורך לעדכן אותה שוב באתר.
