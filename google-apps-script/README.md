# גיבוי אוטומטי ל-Google Sheets - הוראות פריסה

חלק זה **לא רץ בדפדפן** ולא מגיע לאתר "הון" עצמו - זה קוד שרץ בחשבון
הגוגל שלך, בתשתית של גוגל (Google Apps Script). האתר רק שולח אליו נתונים.

## שלב 1: יצירת גיליון חדש

פתח/י [sheets.google.com](https://sheets.google.com) ויצר/י גיליון חדש
וריק. תן/י לו שם (למשל "הון - גיבוי").

## שלב 2: הוספת הקוד

1. בגיליון: תפריט **Extensions → Apps Script**.
2. יפתח עורך קוד עם קובץ ברירת מחדל בשם `Code.gs` שמכיל `function myFunction() {}`.
3. מחק/י את התוכן הקיים, והדבק/י את כל התוכן של הקובץ `Code.gs` שנמצא
   בתיקייה הזו (`google-apps-script/Code.gs`).
4. שמור/י (Ctrl+S / כפתור הדיסקט).

## שלב 3: פריסה כ-Web App

1. בעורך הקוד: כפתור **Deploy** (כחול, למעלה מימין) → **New deployment**.
2. ליד "Select type" - לחצ/י על גלגל השיניים ובחר/י **Web app**.
3. במסך שנפתח:
   - **Execute as**: Me (החשבון שלך).
   - **Who has access**: Anyone (חובה - אחרת האתר לא יוכל לשלוח נתונים).
4. לחצ/י **Deploy**.
5. ייתכן שתתבקש/י לאשר הרשאות - אשר/י (זה הקוד שלך, רץ בחשבון שלך).
6. בסיום יוצג **Web app URL** - כתובת ארוכה שמתחילה ב-
   `https://script.google.com/macros/s/.../exec`. **העתק/י אותה**.

אפשר לבדוק שהפריסה הצליחה על ידי פתיחת הכתובת הזו בדפדפן - אמור
להופיע הטקסט "✓ Web App פעיל ומוכן לקבל סנכרון מהאתר 'הון'".

## שלב 4: חיבור לאתר "הון"

1. פתח/י את אתר "הון", עבור/י ל**הגדרות → סנכרון Google Sheets**.
2. הדבק/י את הכתובת שהעתקת, ולחצ/י **"שמור כתובת"**.
3. לחצ/י **"סנכרן עכשיו"** לבדיקה ראשונה, ואז פתח/י את הגיליון בגוגל -
   אמורה להופיע לשונית **"הון - סנכרון"** עם שורה לכל השקעה: שווי,
   הפקדות נטו, רווח, מס משוער, נטו אחרי מס, ותשואה.

מכאן והלאה - **כל פעולה באתר** (הפקדה, משיכה, עדכון שווי, הוספה/עריכה
של השקעה) תשלח סנכרון מעודכן אוטומטית תוך כשנייה, כל עוד האתר פתוח
בדפדפן. אין צורך ללחוץ "סנכרן עכשיו" שוב באופן שוטף.

**שימו לב:** בכל סנכרון, הגיליון נמחק ונכתב מחדש עם המצב הנוכחי המלא -
זהו "מראה חיה" של ההשקעות שלך, לא יומן היסטוריה שמצטבר. אם רוצים היסטוריה
מלאה לכל נקודת מעקב, אפשר להשתמש בייצוא ה-CSV (הגדרות → ייצוא ל-CSV).

## עדכון הקוד בעתיד

אם הקובץ `Code.gs` בפרויקט משתנה (עדכון עתידי) - יש להעתיק את התוכן
המעודכן לתוך עורך ה-Apps Script (שלב 2) ולפרוס גרסה חדשה: **Deploy →
Manage deployments → עריכת ה-deployment הקיים → Version: New version →
Deploy**. כך כתובת ה-Web App נשארת זהה ואין צורך לעדכן אותה שוב באתר.

## מגבלה טכנית

הבקשה מהאתר נשלחת במצב `no-cors`, כך שהדפדפן לא יכול לקרוא את תשובת
השרת. לכן "✓ סונכרן" שמוצג באתר הוא אופטימי (הבקשה נשלחה בהצלחה), לא
אישור שהסקריפט בצד גוגל אכן רץ בלי שגיאה. אם משהו לא מסתדר - בדוק/י
ב-Apps Script: **Executions** (בתפריט הצד) כדי לראות שגיאות בפועל.
