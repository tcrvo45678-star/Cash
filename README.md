# מעקב כספים אישי

אפליקציית ווב מקומית למעקב אחר חסכונות והשקעות (קופות גמל, השקעה ישירה, פנסיה ועוד),
עם חישוב יתרה לפני ואחרי מס רווחי הון. כל הנתונים נשמרים בקובץ אקסל אמיתי בנתיב
`data/finance.xlsx`, כך שגם אם לא תריץ את האתר תמיד תוכל לפתוח את הקובץ ישירות באקסל.

## הרצה ראשונה

דורש [Node.js](https://nodejs.org) גרסה 18 ומעלה, מותקן במחשב שלך.

```bash
npm install
npm start
```

לאחר מכן פתח בדפדפן: http://localhost:3000

בהרצה הראשונה ייווצר אוטומטית קובץ `data/finance.xlsx` עם 4 אפיקים לדוגמה: קופת גמל -
כלל, קופת גמל - אלטשולר שחם, השקעה ישירה - אקסלנס, ופנסיה. אפשר לערוך, למחוק ולהוסיף
אפיקים נוספים בטאב "אפיקי חיסכון".

## איך זה עובד

- **אפיקי חיסכון** - הגדר את האפיקים שלך (שם, סוג, דמי ניהול מהפקדה, דמי ניהול מצבירה,
  והאם האפיק חייב במס רווחי הון).
- **הפקדות** - בכל פעם שאתה מפקיד כסף לאפיק, רשום כאן את הסכום והתאריך. זה מה שמשמש
  לחישוב "סך ההפקדות" מול היתרה בפועל.
- **יתרות חודשיות** - פעם בחודש, הכנס את היתרה הנוכחית שרואה באתר/אפליקציה של כל גוף
  מנהל. אפשר למלא רק חלק מהאפיקים ולהשלים את השאר מאוחר יותר.
- **לוח בקרה** - מציג עבור כל אפיק ובסך הכול: סך הפקדות, יתרה ברוטו, רווח, מס משוער,
  יתרה נטו אחרי מס, ועלות דמי ניהול שנתית משוערת. בראש הלוח מופיעה התראה אם לא מילאת
  יתרה לחודש הנוכחי עבור כל האפיקים הפעילים.

### איך מחושב המס

מס רווחי הון מחושב לפי 25% (ניתן לשינוי בלוח הבקרה) על הרווח הריאלי בלבד:

```
רווח = יתרה נוכחית - סך ההפקדות
מס = מקסימום(0, רווח) × שיעור המס
יתרה אחרי מס = יתרה נוכחית - מס
```

אם אפיק מסומן כ"לא חייב במס רווחי הון" (למשל אם תרצה לדמות אפיק פטור), לא יחושב עבורו מס.

### דמי ניהול

לכל אפיק ניתן להזין שני שיעורי דמי ניהול נפרדים (כפי שמקובל בקופות גמל ופנסיה בישראל):
דמי ניהול מהפקדה (אחוז מכל הפקדה) ודמי ניהול מצבירה (אחוז שנתי מהיתרה הצבורה). אלו
מוצגים כערך אינפורמטיבי בלוח הבקרה ואינם מנוכים בפועל מהיתרה - מכיוון שהיתרה שאתה
מזין כבר כוללת את הניכוי בפועל שביצע הגוף המנהל.

## הקובץ שלך

הקובץ `data/finance.xlsx` הוא מקור האמת - אפשר לפתוח אותו ישירות באקסל בכל רגע. הוא
לא מועלה ל-git (הוא ב-`.gitignore`) כדי לא לחשוף נתונים כספיים אישיים בריפו. אפשר גם
להוריד אותו מתוך האתר בלחיצה על "הורדת קובץ אקסל" בפינה הימנית העליונה.

**גיבוי**: מומלץ מדי פעם להעתיק את `data/finance.xlsx` למקום בטוח (כונן ענן פרטי,
דיסק חיצוני וכו').
