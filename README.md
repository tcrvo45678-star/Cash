# מעקב כספים אישי

אפליקציית ווב למעקב אחר חסכונות והשקעות (קופות גמל, השקעה ישירה, פנסיה ועוד), עם
חישוב יתרה לפני ואחרי מס רווחי הון. **כל הנתונים נשמרים בגיליון גוגל שיטס אמיתי** -
כך שאפשר להריץ את האתר בכל שירות אחסון חינמי (הנתונים לא נמחקים כשהשרת מתאתחל), ואפשר
גם לפתוח ולערוך את הגיליון ישירות בגוגל שיטס בכל רגע, כולל מהנייד.

## שלב 1: יצירת חיבור לגוגל שיטס (חד פעמי)

האתר מתחבר לגוגל שיטס באמצעות "חשבון שירות" (Service Account) - מעין משתמש רובוט
שיש לו הרשאה לגשת רק לגיליון שתשתף איתו, ולא לכל חשבון הגוגל שלך.

1. **היכנס ל-Google Cloud Console**: https://console.cloud.google.com/ (עם כל חשבון
   גוגל - לא חייב להיות אותו חשבון שבו יושב הגיליון עצמו).
2. **צור פרויקט חדש** (או השתמש בקיים) - תפריט למעלה → New Project.
3. **הפעל את Google Sheets API**: בתפריט החיפוש למעלה חפש "Google Sheets API" →
   לחץ Enable.
4. **צור חשבון שירות**: בתפריט הצד → APIs & Services → Credentials → Create
   Credentials → Service Account. תן לו שם (למשל `cash-tracker`) ולחץ Done (אין
   צורך להוסיף לו הרשאות ברמת הפרויקט).
5. **צור מפתח JSON**: פתח את חשבון השירות שיצרת → לשונית Keys → Add Key → Create new
   key → סוג JSON. יורד קובץ JSON למחשב שלך - **שמור אותו במקום בטוח**, הוא מכיל את
   כל הפרטים הדרושים.
6. בתוך קובץ ה-JSON יש שני שדות שתצטרך:
   - `client_email` - זו כתובת המייל של חשבון השירות (נראית כמו
     `cash-tracker@your-project.iam.gserviceaccount.com`)
   - `private_key` - מחרוזת ארוכה שמתחילה ב-`-----BEGIN PRIVATE KEY-----`

## שלב 2: יצירת הגיליון ושיתופו

1. צור גיליון גוגל שיטס חדש בכל חשבון גוגל שתרצה (https://sheets.google.com) - אפשר
   גיליון ריק לגמרי, האתר ימלא אותו אוטומטית בפעם הראשונה שירוץ.
2. לחץ **שיתוף (Share)** ושתף את הגיליון עם כתובת המייל של חשבון השירות
   (ה-`client_email` משלב 1), עם הרשאת **עורך (Editor)**.
3. העתק את **מזהה הגיליון** מתוך כתובת ה-URL של הגיליון:
   `https://docs.google.com/spreadsheets/d/`**`המזהה-נמצא-כאן`**`/edit`

## שלב 3: הרצה

### הרצה מקומית במחשב שלך

דורש [Node.js](https://nodejs.org) גרסה 18 ומעלה.

```bash
npm install
cp .env.example .env
```

ערוך את קובץ ה-`.env` שנוצר, ומלא בו את שלושת הפרטים:
- `GOOGLE_SERVICE_ACCOUNT_EMAIL` - ה-`client_email` משלב 1
- `GOOGLE_PRIVATE_KEY` - ה-`private_key` משלב 1 (עם המרכאות והגרשיים `\n` בדיוק כפי
  שהם מופיעים בקובץ ה-JSON)
- `GOOGLE_SHEET_ID` - מזהה הגיליון משלב 2

לאחר מכן:
```bash
npm start
```
ופתח בדפדפן: http://localhost:3000

### הרצה בענן (חינמי, כדי לקבל קישור זמין מכל מקום)

לדוגמה עם [Render](https://render.com) (יש חבילה חינמית):
1. הירשם ל-Render וחבר את חשבון ה-GitHub שלך.
2. New → Web Service → בחר את הריפו של הפרויקט הזה, ענף
   `claude/personal-finance-tracker-bpp045`.
3. הגדרות בנייה: Build Command = `npm install`, Start Command = `npm start`.
4. תחת Environment, הוסף את שלושת משתני הסביבה מהשלב הקודם
   (`GOOGLE_SERVICE_ACCOUNT_EMAIL`, `GOOGLE_PRIVATE_KEY`, `GOOGLE_SHEET_ID`).
5. Create Web Service - Render ייתן לך קישור ציבורי (כמו
   `https://your-app.onrender.com`) שאפשר לפתוח מכל מכשיר.

בחבילה החינמית השרת "נרדם" אחרי כמה דקות בלי שימוש ומתעורר לאט בפעם הבאה שנכנסים -
זה בסדר גמור כי הנתונים נשמרים תמיד בגוגל שיטס ולא בשרת עצמו.

## איך זה עובד

- **אפיקי חיסכון** - בפעם הראשונה שהאתר רץ, הוא יוצר בגיליון 4 אפיקים לדוגמה: קופת
  גמל - כלל, קופת גמל - אלטשולר שחם, השקעה ישירה - אקסלנס, ופנסיה (ריק, ממתין
  שתפתח). אפשר לערוך, למחוק ולהוסיף אפיקים נוספים בטאב "אפיקי חיסכון".
- **הפקדות** - בכל פעם שאתה מפקיד כסף לאפיק, רשום כאן את הסכום והתאריך. זה מה שמשמש
  לחישוב "סך ההפקדות" מול היתרה בפועל.
- **יתרות חודשיות** - פעם בחודש, הכנס את היתרה הנוכחית שרואה באתר/אפליקציה של כל גוף
  מנהל. אפשר למלא רק חלק מהאפיקים ולהשלים את השאר מאוחר יותר.
- **לוח בקרה** - מציג עבור כל אפיק ובסך הכול: סך הפקדות, יתרה ברוטו, רווח, מס משוער,
  יתרה נטו אחרי מס, ועלות דמי ניהול שנתית משוערת. בראש הלוח מופיעה התראה אם לא מילאת
  יתרה לחודש הנוכחי עבור כל האפיקים הפעילים.

### איך מחושב המס

מס רווחי הון מחושב לפי 25% (ניתן לשינוי בלוח הבקרה) על הרווח הריאלי בלבד:

```
רווח = יתרה נוכחית - סך ההפקדות
מס = מקסימום(0, רווח) × שיעור המס
יתרה אחרי מס = יתרה נוכחית - מס
```

אם אפיק מסומן כ"לא חייב במס רווחי הון" (למשל אם תרצה לדמות אפיק פטור), לא יחושב עבורו מס.

### דמי ניהול

לכל אפיק ניתן להזין שני שיעורי דמי ניהול נפרדים (כפי שמקובל בקופות גמל ופנסיה בישראל):
דמי ניהול מהפקדה (אחוז מכל הפקדה) ודמי ניהול מצבירה (אחוז שנתי מהיתרה הצבורה). אלו
מוצגים כערך אינפורמטיבי בלוח הבקרה ואינם מנוכים בפועל מהיתרה - מכיוון שהיתרה שאתה
מזין כבר כוללת את הניכוי בפועל שביצע הגוף המנהל.

## הגיליון שלך

כפתור "פתיחת הגיליון בגוגל שיטס" בפינה הימנית העליונה של האתר פותח את הגיליון החי
ישירות. כפתור "הורדת קובץ אקסל" מוריד עותק `.xlsx` עדכני של כל הנתונים למחשב שלך -
מומלץ מדי פעם, כגיבוי נוסף.

**חשוב**: אל תעלה את קובץ ה-`.env` שלך (או את קובץ ה-JSON שהורדת מגוגל) ל-GitHub או
לכל מקום ציבורי - הוא מכיל מפתח פרטי שנותן גישה לכתיבה לגיליון שלך. קובץ `.gitignore`
כבר מוגדר לא לכלול את `.env`.
